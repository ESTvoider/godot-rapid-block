# Rapid Block

快速 3D 白盒搭建插件（Godot 4.7）。在编辑器右侧 Dock 中点击放置 CSG 形状，支持布尔挖除、网格/表面吸附、门窗生成、复制工具，以及烘焙为 Mesh、导出 MeshLibrary 与结构色标记。

## 安装与启用

1. 将 `addons/rapid_block/` 文件夹复制到你的项目 `addons/` 目录下。
2. 打开 **项目 → 项目设置 → 插件**，启用 **Rapid Block**。
3. 编辑器右侧会多出一个 Dock 面板（右上方），即可开始使用。

> 本仓库已预置启用，直接打开任意 3D 场景即可使用。

## 界面概览

Dock 面板自上而下分区：

| 区域 | 说明 |
| --- | --- |
| 开始放置 | 放置模式开关（高亮即激活） |
| 操作模式 | 添加（Union）/ 挖除（Subtract）/ 相交（Intersect） |
| 形状 | 方块 / 圆柱 / 球体 / 平面 / 斜坡 / 台阶 / 胶囊 |
| 尺寸 | 预设下拉框 + X / Y / Z 微调 |
| 网格吸附 | 启用开关 + 网格大小 |
| 旋转增量 | R 键 / 滚轮单次旋转的角度，实时角度显示 |
| 拖拽与吸附 | 拖拽拉伸、表面吸附、拖拽高度 |
| 门窗 | 点击墙面生成门/窗 |
| 工具 | 烘焙、阵列/镜像/路径复制、导出 MeshLibrary、结构色 |

## 快速上手

1. 打开一个 3D 场景（如本仓库的 `scenes/dev_test.tscn`）。
2. 点击 Dock 上的 **开始放置**。
3. 在 3D 视口中移动鼠标可看到半透明幽灵预览，**左键点击**放置一个方块。
4. **右键** 或按 **Esc** 退出放置模式。

## 放置操作

### 点击放置
左键点击视口即可放置当前形状。放置位置按优先级归属：
- 选中了某个 CSG 节点 → 作为该节点的子节点挂入；
- 否则挂入场景中已有的 `Whitebox` 组合器；
- 都没有则自动创建一个 `Whitebox` 组合器。

### 拖拽拉伸
默认开启。在视口中按住左键拖出一个矩形，松开后按矩形宽深 + 「拖拽高度」生成形状（斜坡/台阶底部贴地，其余抬高一半）。

### 旋转
- 按 **R** 或滚动鼠标滚轮，按「旋转增量」步进旋转幽灵预览；
- 贴墙吸附时自动朝墙面法线方向，无需手动旋转。

### 网格吸附
勾选「网格吸附」后，放置点会吸附到「网格大小」（默认 0.5）的整数倍上。

### 表面吸附
勾选「表面吸附」后，点击场景中的 CSG 表面可把形状直接贴到该表面：
- 吸附到地面/顶面/斜面时，形状按自身尺寸沿法线偏移放置；
- 吸附到墙面时，自动对齐墙面朝向并沿法线偏移半个厚度。

## 操作模式

| 模式 | 颜色 | 用途 |
| --- | --- | --- |
| 添加（Union） | 灰 | 普通拼搭（默认） |
| 挖除（Subtract） | 半透明红 | 从已有形状中挖掉一块，用于开洞 |
| 相交（Intersect） | 半透明绿 | 只保留形状相交部分 |

> 挖除/相交的材质为插件运行时生成，不影响共享的白色材质资源。

## 形状与尺寸

支持 7 种形状：方块、圆柱、球体、平面、斜坡、台阶、胶囊。

「尺寸预设」快速选择常用尺寸：
- **默认**：所选形状的默认大小
- **墙体（0.2 厚）**：3.0 × 2.8 × 0.2
- **标准层高（3m）**：4.0 × 3.0 × 0.2
- **地板**：6.0 × 0.1 × 6.0

也可用 X / Y / Z 三个微调框手动指定尺寸（0.05–100，步进 0.1）。

## 门窗生成

1. 勾选 **表面吸附**；
2. 在「门窗」下拉框选择：门洞 / 窗洞 / 门（带框）/ 窗（带框）；
3. 点击竖直墙面（表面吸附会命中墙面），自动挖出洞并（可选）加上门/窗框。

内置尺寸常量：门宽 0.9、门高 2.1；窗宽 1.5、窗高 1.2、窗台高 0.9；框厚 0.06。

## 复制工具（需先选中节点）

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| 阵列复制 | 行 × 列 × 间距 | 沿 X（列）与 Z（行）铺开，含源节点 |
| X 镜像 / Z 镜像 | — | 沿 X / Z 轴镜像复制一份 |
| 沿路径复制 | 份数 + 终点偏移 (X/Y/Z) | 从源位置到「源位置 + 偏移」均匀等分复制 |

所有复制均在选中节点同一父级下创建副本，支持撤销。

## 烘焙为 Mesh

选中一个 CSG 节点（如 `Whitebox` 组合器），点击 **烘焙选中 CSG → Mesh**：
- 生成 `*_Baked` 节点，内含多个 MeshInstance3D 与一个带碰撞的 StaticBody3D；
- 原 CSG 节点隐藏（不删除，可撤销恢复）；
- 适合把白盒转成正式可用的静态几何。

## 导出 MeshLibrary

1. 选中一个已渲染的组合器（CSG 需在编辑器中至少显示一帧）；
2. 在「导出路径」填入保存位置（默认 `res://whitebox_meshes/whitebox.tres`）；
3. 点击 **导出选中 CSG**，组合器的每个子网格将成为一个 MeshLibrary item，可配合 GridMap 使用。

> 提示：若提示「CSG 几何为空」，说明组合器尚未渲染一帧，先让场景在编辑器中显示片刻再导出。

## 结构色

选中节点后点击「结构色」按钮，可为节点及其所有后代 CSG 递归设置独立材质颜色，用于标注类型：

| 类型 | 颜色 | 常见用途 |
| --- | --- | --- |
| 墙体 | 浅灰 | 承重墙 |
| 地板 | 中灰 | 地面 |
| 结构 | 橙黄 | 承重结构 |
| 可交互 | 青绿 | 可交互物（门、开关等） |

「添加颜色」可为后续放置的形状设定自定义颜色（作用于共享材质）。

## 快捷键汇总

| 操作 | 按键/手势 |
| --- | --- |
| 放置 / 拖拽拉伸 | 左键点击 / 按住左键拖拽 |
| 旋转 | R 键 或 鼠标滚轮 |
| 退出放置模式 | 右键 或 Esc |
| 切换/关闭场景 | 自动退出放置模式 |

## 常见问题

- **放置后看不到形状？** 确认处于「开始放置」激活状态，且视口中有 CSG 表面或地面可点；检查「表面吸附」是否导致吸附到远处表面。
- **导出提示几何为空？** 组合器需在编辑器中渲染至少一帧后再导出。
- **形状挂到了奇怪的位置？** 表面吸附会优先命中最近的 CSG 表面，若不需要请关闭「表面吸附」。
- **与 `scenes/test_whitebox.tscn` 的区别？** 该场景是自动化测试画布，运行测试会清空其内容；手工测试请使用 `scenes/dev_test.tscn`（已预置地板、双墙、圆柱、斜坡、台阶与环境光）。
- **右侧看不到 Dock 面板？** 编辑器窗口过窄时，右侧 Dock 标签会被折叠。拉宽编辑器窗口，或展开编辑器窗口右上角（或标签栏）的折叠菜单找回 Rapid Block 面板。
